# Glossary

- RBAC: role-based access control.
- Tenant: organization or workspace-like boundary.
- UserTenant: relation between user and tenant.
- UserTenantRole: role assignment for a user within a tenant.
- tenantadmin: default owner/admin role used when creating tenants.
- member: default role used when approving tenant membership.
- LinkUserTenantRequest: request/invite flow connecting users and tenants.
- Access token: JWT cookie used for authenticated requests.
- Refresh token: opaque token stored as hash and rotated.
- Repository: write/persistence adapter.
- Query: read adapter.
- Use case: application-level orchestration of a behavior.
- Rule: business validation component.
